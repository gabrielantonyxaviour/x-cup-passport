1. Show the X Cup Passport hero and non-cash fixture label.
2. Mint a passport for a nation.
3. Submit a prediction for the labeled fixture.
4. Resolve the fixture through the admin resolver.
5. Settle the pick and show score/passport changes.
6. Create and settle a Banter receipt.
7. Show explorer links if deployed, otherwise show local/anvil proof and the deployment blocker.
