# API Plan

Date: 2026-05-22

## Architecture

This MVP uses no hidden backend. The core source of truth is Solidity contract state and events. The frontend ships with labeled fixture metadata only for pre-tournament demo context.

## Contracts

| Contract | Responsibility | Real proof path |
|---|---|---|
| `XCupPassport` | Mint fan passport, store nation, score, prediction count, badge count | Foundry tests, anvil deployment, X Layer deployment when funded |
| `MatchResolver` | Admin-created fixtures and admin-resolved results | Foundry tests and deployment script |
| `PredictionPool` | Non-cash prediction entry and settlement against resolver | Foundry tests and UI transaction flow |
| `BanterBond` | Non-cash rivalry create/accept/settle receipt | Foundry tests and UI transaction flow |

## Frontend Data

| Data | Source | Policy |
|---|---|---|
| Demo fixtures | `src/data/fixtures.ts` | Labeled as fixture/demo data in UI and docs |
| Contract addresses | `src/config/contracts.ts`, generated by deployment scripts | Empty/local until real deployment occurs |
| Explorer links | Derived from configured chain and tx hash | Only shown as real when a tx hash exists |
| Leaderboard | Contract reads plus local demo/test artifacts | Never described as live global leaderboard unless indexed from deployed contracts |

## Secrets

| Env var | Purpose | Required for |
|---|---|---|
| `X_LAYER_TESTNET_RPC_URL` | Override default testnet RPC | Deployment/smoke checks |
| `X_LAYER_DEPLOYER_PRIVATE_KEY` | Funded deployer key | Live X Layer deployment |
| `VITE_WALLETCONNECT_PROJECT_ID` | Optional WalletConnect project id | Production wallet connect enhancement |

No secrets are committed. `.env.example` will document variables.

## Fallback Policy

Fixtures are allowed only in tests, seed scripts, and clearly labeled demo UI. The product may be `demo-ready` with local/anvil proof plus blocked X Layer deployment; it cannot be `submit-ready` without public repo, X post, and X Layer deployment proof.
